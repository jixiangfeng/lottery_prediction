# 双色球覆盖优先分散组合挑战器 v2

## 定位

`ssq_diversified_portfolio_v2` 是独立、固定、仅供研究的组合构造器。它不修改
`ssq_ensemble_v1` 的概率、在线更新、硬门禁、既有集中式 Top5 控制 A，也不形成
正式推荐。所有合法单注机会均等；35 注仅对应单注成本的 35 倍，不产生预测优势。

## 固定 B 构造

1. 红球按当前边际概率降序排列，同概率按球号升序。
2. 前 33 个槽位依次放入全部 33 个红球，随后追加排名第 1、2 的红球各一次。
3. 35 个槽位按固定 7 行×5 组蛇形布局分配：偶数行组 1→5，奇数行组 5→1。
4. 不执行交换、搜索或 CLI 调参；覆盖约束优先于任何模型或红球对分数。
5. 蓝球取当前概率 Top5 互异号码，排名第 i 的蓝球固定分配给第 i 组。
6. 每组红7与所属蓝球展开 7 注，共 35 注唯一票。

硬断言：5 组红7互异、红球并集恰好 33、仅概率排名前二各重复一次、最大红球
暴露 2、任意两组交集不超过 3、5 个蓝球互异、35 注全部唯一。任一协议、概率
绑定、结构或展开票审计不一致时失败关闭。

## 严格前序历史评估

运行：

```bash
make ssq-diversified-portfolio-v2-history
```

固定读取 `data/ssq/official_history.csv`，预热 120 期，之后每期严格执行“先预测并
构造/评分，后更新模型状态”。比较：

- A：既有集中式 Top5 精确构造，共享模型 Top1 蓝球，仅作控制。
- B：覆盖优先分散组合 v2。
- C：每期 32 组固定 SHA-256 种子的同成本随机组合；每组含 5 个随机合法红7、
  5 个互异蓝球与 35 注唯一票，种子不依赖开奖结果和模型。

报告包含 A/B/C 汇总、B-A 与 B-C 差值、逐期明细、单侧配对检验及协议/数据/报告
哈希。检验属于事后多重比较的描述性结果，不作为门禁，也不使用官方奖级表述。

输出：`reports/retrospective/ssq_diversified_portfolio_v2_full_history.json`。

仅未来 500 期 HMAC 影子链见
`docs/ssq_diversified_portfolio_v2_prospective.md`；该链不改变本页任何回溯结果或模型。

# 大乐透7+2 C5在线Hedge融合前瞻协议

## 1. 定位

`C5_ONLINE_HEDGE_LOGPOOL`是C1/C2/C3之上的单机制挑战者：只根据开奖前已经结算的专家proper loss动态调整三位专家的融合权重。不新增特征、不增加注数、不修改C1～C4。

本协议在既有Warmup、Search与Validation结果已经被查看后建立；索引`2401:2901`的最新500期仍保持v1 Frozen未读取，且不重新分配给C5。因此C5任何索引`0:2401`历史重放均固定标记`exploratory_reused_development`，不得包装为独立Validation/Frozen证据；v1 Frozen继续密封。C5正式证据只来自协议注册后的真实未来开奖。

## 2. 固定算法

- 专家顺序：`C1_LONG_RIDGE`、`C2_MULTISCALE_RIDGE`、`C3_PAIR_GRAPH_RIDGE`；
- 专家原始logit仍按全局25期区块、严格前序拟合；
- Hedge回看窗口：最近200个已结算目标；
- 专家评价分布：前后区均固定`tau=1.0`、`epsilon=0.10`；
- 单期归一化损失：

  `0.5 * (frontSetLogLoss / log(C(35,5)) + backSetLogLoss / log(C(12,2)))`；

- 学习率：`eta=8.0`；
- 权重下限：每位专家`0.10`；
- 原始权重：对最近窗口平均归一化损失执行`softmax(-eta * meanLoss)`；
- 最终权重：`0.10 + 0.70 * rawWeight`，三项精确和为1；
- 无已结算损失时权重固定`1/3`；
- C5前区/后区logit均为三位专家对应logit的同一组加权平均；
- C5输出校准永久固定为C4既有参数：前区`tau=1.0, epsilon=0.10`，后区`tau=2.0, epsilon=0.20`；
- 选择前区边际概率Top7、后区Top2，展开恰好21张唯一5+2票；
- 平局按号码升序，所有浮点计算和哈希必须确定性。

不得通过CLI修改窗口、eta、权重下限、校准参数、TopK或成本。

## 3. 严格前序与防泄漏

对目标`t`：

1. 基础专家只消费各自全局25期拟合截止点以前的数据；
2. C5权重只消费目标`t`以前已结算专家损失；
3. 先锁定C5权重、完整概率、Top7/Top2和21票；
4. 后读取目标期开奖并评分；
5. 最后才将该期专家损失加入窗口。

改变目标或未来期开奖结果不得改变较早目标的权重、分数、号码或指纹。

## 4. 历史执行诊断

允许在全量已查看历史上重放，仅用于验证：

- 无未来泄漏；
- 权重有限且和为1；
- 固定成本21票；
- 与C4、精确均匀和每期512组确定性随机7+2的描述性差异；
- 前区命中0～5、后区命中0～2、组合效用和固定100期块。

报告必须写明：

```text
evidenceStatus=exploratory_reused_development
independentEvidence=false
formalGate=false
formalOutput=uniform_abstain
```

历史诊断无论多好都不得自动创建正式推荐。

## 5. 未来500期前瞻证据

仅在确认本地官方数据新鲜、当前目标尚未开奖且已存在开奖前快照时开始：

- 总计500期，固定5个连续100期块；
- 比较C5、固定C4、精确均匀和每期512组同成本随机7+2；
- 记录集合LogLoss、边际Brier、前/后区命中分布、21票结构、组合效用；
- HMAC-SHA256链只追加，密钥在状态目录外且权限不高于0600；
- 每次只结算恰好一个已锁定目标，禁止回填、跳期、重签和追补。

## 6. 固定准入门槛

500期结束后，C5必须同时满足：

1. 联合集合LogLoss优于精确均匀，移动块Bootstrap单侧`p<=0.05`；
2. 前区、后区集合LogLoss均不差于精确均匀；
3. 前区Brier不高于`6/49`，后区Brier不高于`5/36`；
4. 5个100期块至少4块联合LogLoss改善非负，最差块不低于`-0.05`；
5. 组合效用高于每期512组随机均值，且至少4/5效用块非负；
6. C5相对固定C4的配对联合LogLoss均值改善大于0，移动块Bootstrap单侧`p<=0.05`；
7. 不存在成本、数据边界、快照、HMAC或完整性违规。

任何一项失败即`rejected/uniform_abstain`。通过也只进入人工复核，不自动激活、不自动增加预算。
